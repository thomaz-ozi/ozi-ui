Verificador de tema de tokens

Uso: _verificador-tema.html?tema=temas-gerados/oceano (a pasta tem tokens.css e dark.css). Sem tema, mede o próprio default (linha de base). Critérios, os mesmos do prompt oficial da página "Temas e skins":

  1. Forma: só os seletores :root (tokens.css) e [data-ozi-theme="dark"] + @media (prefers-color-scheme: dark) { :root:not([data-ozi-theme="light"]) } (dark.css); só propriedades --ozi-*; nenhum valor vazio.
  2. Só token com efeito: todo token declarado é lido por algum CSS do pacote (direto ou via outro token).
  3. Escuro coerente: os dois blocos do dark.css declaram os mesmos tokens com os mesmos valores.
  4. Contraste (WCAG 2.1, claro e escuro): texto ≥ 4,5:1; indicador de foco ≥ 3:1. Os pares em que o próprio default fica abaixo têm a meta do default (não pode piorar).
