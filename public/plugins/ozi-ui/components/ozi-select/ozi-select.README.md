# ozi-select.js

**Versão:** 6.4.0 · **Camada:** `components/ozi-select/`

Select customizado com busca, seleção múltipla, grupos, imagens e busca remota. Modo *creatable*
(cria opção a partir do texto digitado), rodapé de ação e botões de ação por opção.

> defasada, exemplos em jQuery (removido na v2) e atributos que o componente não lê mais.

> um ponteiro curto, que não tem como envelhecer sozinho.
